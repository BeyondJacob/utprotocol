# UTP / UTProtocol: Universal Thought Protocol for Multi-Agent LLM Systems

Performance benchmarking framework comparing Rust-optimized multi-agent systems against Python baselines (LangChain, AutoGen).

## Features

- 🚀 4-5x faster multi-agent inference
- 💾 2-3x lower memory usage
- 🔧 Works with GPT-OSS 20B and Llama 3.1 8B (4-bit Quantitzed)
- 📊 Real-time benchmarking dashboard
- 🐳 Docker support for reproducibility
- ☁️ Cloud deployment ready (AWS, RunPod)
